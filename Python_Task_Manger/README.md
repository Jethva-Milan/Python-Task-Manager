# Python Task Manager

A beginner-friendly task management application built using Python.

## Features
- Add tasks
- View tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using JSON
- Handle invalid user input

## Technologies Used
- Python 3
- JSON
- os module

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open the project folder.
4. Run `python task_manager.py` in the terminal.
